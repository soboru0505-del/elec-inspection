## 🚀 무료 배포 방법 (Netlify — 가장 쉬움)

### 1단계: 회원가입
👉 https://netlify.com 접속 → GitHub 계정으로 무료 가입

### 2단계: 배포 (드래그 앤 드롭)
1. netlify.com 로그인 후 대시보드 이동
2. **"Sites"** 메뉴 클릭
3. 이 폴더 전체(`elec-inspection-pwa`)를 화면에 **드래그 앤 드롭**
4. 자동으로 배포 완료! 🎉

### 3단계: URL 받기
- 배포 후 `https://랜덤이름.netlify.app` 형태의 URL 생성
- 원하면 무료로 도메인 이름 변경 가능

---

## 📱 앱으로 설치하는 방법

### 안드로이드 (크롬)
1. 배포된 URL을 크롬으로 접속
2. 우측 상단 메뉴(⋮) → **"홈 화면에 추가"**
3. 설치 완료 → 앱 아이콘 생성

### iPhone (사파리)
1. 배포된 URL을 사파리로 접속
2. 하단 공유 버튼(□↑) → **"홈 화면에 추가"**
3. 설치 완료 → 앱 아이콘 생성

## ✨ 앱 기능

- ✅ 기본사항 입력 (달력, 횟수 스크롤)
- ✅ 저압설비 16항목 점검 (○/× 버튼)
- ✅ 특고(고압)설비 16항목 점검
- ✅ 전기 측정값 입력 (전압/전류/누설전류)
- ✅ 역률/전력 입력
- ✅ 3단계 서명 워크플로우
  - 1단계: 업체담당자 입력 + 서명
  - 2단계: 업무담당자 검토 + 서명
  - 3단계: 확인자 최종 서명
- ✅ A4 인쇄 / PDF 저장
- ✅ 오프라인 사용 가능 (설치 후)
